Explicación del codigo en c

Codigo:

            
    #include <stdio.h>

    int main() 
    {
        int edad;
        printf("¿Cuántos años tienes? ");
        scanf("%d", &edad);

        if (edad >= 18) 
        {
            printf("Eres mayor de edad.\n");
        } 
        else 
        {
            printf("Eres menor de edad.\n");
        }

        return 0;
    }

Librerias

Las librerías son archivos externos a los que se les hace referencia en un código con #include, estos contienen funciones predefinidas que agilizan el desarrollar programas.
En este ejemplo la biblioteca usada es <stdio.h>

Función principal: int main()

Este es el cuerpo principal del código donde se ve toda la lógica del programa

Definir variables

Es importante definir las variables al inicio despues del int main () así se lleva un mejor cotrol del programa y en caso de necesitar modificar algo es más facil de ubicar.

Funciones en el código

Estas funciones printf();scanf();if(){}else{}provienen de la libreria ya mensionada

printf();

Esta se encarga que el texto entre comillas qeu se encuentre dentro de los parentesis se muestre en la pantalla

scanf();

Este se encarga que lo que se introdusca se almacene en la variable referenciada por el &

if(){}else{}

Comprueba si lo que se encuentra dentro del parentesis del if es verdadero, en caso de que lo sea se ejecuta el código que se encuentre inmediatamente despues, en caso de que sea falso se ejecutará lo que siga del else
