Explicación del codigo en c

Codigo:

            
    #include <stdio.h>

    int main() 
    {
        int edad;
        printf("¿Cuántos años tienes? ");
        scanf("%d", &edad);

        if (edad >= 18) 
        {
            printf("Eres mayor de edad.\n");
        } 
        else 
        {
            printf("Eres menor de edad.\n");
        }

        return 0;
    }

Librerias

Las librerías son archivos externos a los que se les hace referencia en un código con #include, estos contienen funciones predefinidas que agilizan el desarrollar programas.
En este ejemplo la librería usada es <stdio.h>

Función principal: int main()

Este es el cuerpo principal del código donde se ve toda la lógica del programa

Definir variables

Es importante definir las variables al inicio después del int main() así se lleva un mejor control del programa y en caso de necesitar modificar algo es más fácil de ubicar.

Funciones en el código

Estas funciones printf();scanf();if(){}else{}provienen de la librería ya mencionada

printf();

Esta se encarga que el texto entre comillas que se encuentre dentro de los paréntesis se muestre en la pantalla

scanf();

Este se encarga que lo que se introduzca se almacene en la variable referenciada por el &

if(){}else{}

Comprueba si lo que se encuentra dentro del paréntesis del if es verdadero, en caso de que lo sea se ejecuta el código que se encuentre inmediatamente después, en caso de que sea falso se ejecutará lo que siga del else

return

Termina la ejecución del programa indicando que todo salió bien o si surgió algún error
